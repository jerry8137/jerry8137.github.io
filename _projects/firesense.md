> See Through the Smoke. Command with Clarity.

FireSense is a modular thermal and radar sensing system built to help firefighters navigate smoke-filled interiors. By fusing thermal imaging with radar-based SLAM, it generates real-time maps of the environment when human visibility is gone, giving incident commanders the operational awareness they need to coordinate a response.

Version 1.0 mounts on a ground platform or can be carried by a firefighter. Version 2.0 targets further miniaturization so the sensing stack integrates directly into firefighter gear, letting command centers track personnel location in real time.
